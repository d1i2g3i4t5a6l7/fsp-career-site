# Изменения во фронте (`frontend/`)

Исходник — проект `fsp-career-site`, скопирован в `frontend/` 10.10.2026 байт в байт. Здесь записано всё, что после этого менялось: что, где, зачем и как откатить. Код целиком не приводится — только место и суть.

Правило: логику и внешний вид сайта без согласования не меняем. Любая правка фронта сначала попадает сюда.

## 1. Переход на Vite — 10.10.2026

**Зачем.** Раньше страница при каждом открытии скачивала с unpkg.com React и Babel (3 МБ) и собирала весь JSX прямо в браузере. Теперь JSX собирается заранее, React лежит в проекте. Сайт открывается без интернета (кроме шрифтов Google, у которых есть локальная замена в `public/ds/fonts`) и быстрее: первое открытие 1,3 с → 0,26 с, повторное 0,55 с → 0,04 с.

**Логика и вид не менялись.** Ни один экран, текст, стиль, расчёт, адрес страницы и способ хранения данных в браузере не тронут.
