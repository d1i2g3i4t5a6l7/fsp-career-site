# ФСП Карьера

Платформа подбора ИТ-специалистов с верифицированным профилем участника ФСП (Федерация спортивного программирования России). Хакатон ФСП, спецтрек, 2026.

Обратная механика найма: кандидат подтверждает грейд тестом → получает категорию (направление × грейд) → работодатель находит его и пишет первым, сразу с вилкой зарплаты → контакты открываются после согласия кандидата.

## Что внутри

- Главная страница с анимированной сценой «код → оценка ИИ → категория → приглашение».
- Вход с тестовыми аккаунтами и регистрация кандидата в 7 шагов: аккаунт, почта, ФСП ID, опрос, грейд, тест на время, категория.
- Кабинет кандидата: профиль и место в категории, грейд и тесты (включая вайбкодинг-тест с ИИ-ассистентом), резюме, приглашения, задания, вакансии, настройки.
- Кабинет работодателя: потребность, подборка (рейтинг / таблица / досье), банк кандидатов, приглашения, вакансии и отклики, проверка оценок ИИ, профиль компании.

## Запуск

JSX собирает [Vite](https://vite.dev) — заранее, а не в браузере при каждом открытии. Нужен Node.js 18, 20 или 22+.

```bash
npm install      # один раз
npm run dev      # разработка: http://localhost:5173, страница обновляется сама при сохранении файла
npm run build    # готовый сайт в dist/
```

Вместе со всей платформой сайт поднимается из корня репозитория: `docker compose up -d --build`, адрес http://localhost:8080.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Страница: подключает React, дизайн-систему, данные и `main.jsx` |
| `main.jsx` | Подключает файлы `.jsx` по порядку |
| `app.jsx` | Маршрутизация и состояние приложения |
| `public/app.css` | Стили приложения и главной |
| `public/data.js` | Демо-данные и формула рейтинга (тест 45 · стек 25 · ФСП 15 · активность 10 · эксперт 5) |
| `ui.jsx` | Общие компоненты и оболочка кабинета |
| `pixel.jsx` | Пиксель-арт и анимированные иллюстрации |
| `landing.jsx` | Главная страница и вход |
| `onboarding.jsx` | Регистрация, 7 шагов |
| `candidate.jsx` | Кабинет кандидата |
| `vibe.jsx` | Вайбкодинг-тест с ИИ-ассистентом |
| `shortlist.jsx` | Подборка, карточка кандидата, форма приглашения |
| `employer.jsx` | Кабинет работодателя |
| `public/ds/` | Дизайн-система ФСП: токены, шрифты, компоненты |
| `public/assets/` | Логотипы и паттерн |
| `public/vendor/` | React 18.3.1 — тот же файл, что раньше грузился с unpkg.com |

Всё из `public/` отдаётся браузеру как есть, по тем же адресам, что и раньше (`app.css`, `data.js`, `assets/…`).

## ИИ-ассистент в вайбкодинг-тесте

На claude.ai ассистент отвечает через Claude. При запуске в другом месте он переключается на заготовленный сценарий из трёх ответов.
